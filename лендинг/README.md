# «Кольцо Раздора» — HTML-лендинг IT-тимбилдинга

Готовый адаптивный лендинг с тремя игровыми уровнями, библиотекой 10 миссий, блоком 12 soft skills и заявкой в Telegram.

- Исходная папка: `лендинг/index.html` и локальные изображения в `лендинг/assets/`.
- Для сайта Next.js создана копия `public/лендинг/index.html` и `public/лендинг/assets/`. После обычной сборки и деплоя будет доступно по пути `/лендинг/`.
- Фирменные цвета: петроль `#087F86`, глубокий петроль `#066A70`, оранжевый `#FF7043`, молочный `#FFF9F3`.
- Изображение Юлии встроено в локальный SVG из материала, уже находившегося в репозитории.
- Контакт: https://t.me/julia_uvarova_psy.

Для открытия исходной страницы достаточно открыть `index.html` при сохранённой рядом папке `assets/`. Внешние JS-библиотеки и сборка не нужны.

**Права на сеттинг:** используются мотивы и имена из «Властелина колец»; при коммерческом использовании узнаваемых персонажей и наименований требуется разобраться с разрешениями или заменить их оригинальными образами.
